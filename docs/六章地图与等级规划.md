## 确保主线结束60级

- 从1级开始，第1—6章结算等级依次保底为10、20、30、40、50、60。
- 累计经验初版公式：100×(等级−1)²＋50×(等级−1)；到60级累计经验为351050。
- 每张地图任务首次结算时，补足当前经验与该图目标等级累计经验之间的差额。自然刷怪与任务固定经验先入账，再计算差额；已超目标时不补、不降级。
- 因此只走必需主线也能到60级，不要求清光怪物、重复刷图或完成支线。该保底机制需在后续等级系统中实现，当前灰盒没有等级经验系统。
- 五人队伍按每位角色自己的任务完成标记分别结算，禁止重复领取；中途加入者按自身进度补做或补结算，不能只读房主等级。
- 正式版本若允许超过60级，以上确保至少60级；本轮主线规划暂以60级为战役终点，满级与终局等级上限待另定。
- 普通天赋总上限140不等于主线自动给140。等级与剧情分别发多少点另行制定；当前灰盒给满140只是构筑测试额度。

## 小地图对应规则

- 每张地图分别保存探索格、出入口、NPC、传送点、宝箱与任务标记，不把51图压进一张局部小地图。
- M显示当前地图，另设章节路线页显示本章8—9图连接；世界页显示六章入口。
- 未完成前置任务的出口显示锁定原因；目标在别图时指向正确出口，而不是穿过墙壁指向远方坐标。
- 剧情节点附着于具体地图，地图可以包含多个调查、战斗与交互节点。

## 制作与验收顺序

1. 先做第一章8张独立灰盒、场景切换与检查点，再按同一数据结构扩展其余章。
2. 实现角色等级经验、单次任务奖励与地图等级保底。
3. 将局部小地图从整条试验路线改为按map_id分区保存。
4. 自动验证每章8—9图、51图连续连接、终点60级、奖励重复领取无效及五人个人结算。
5. 人工验证每章剧情节奏、怪物密度与实际升级速度。
