# 白雪主线地图与小地图

更新：2026-10-27。正式战役规划详见 `六章地图与等级规划.md` 与 `data/campaign_maps.json`。

## 六章结构

六章各有8—9张独立剧情地图，共51张必经图。剧情任务承载在地图内部，魔镜、猎人放行、七人小屋、三次敲门和玻璃棺是故事节点，不代表整章只制作一张地图。地图应有独立入口出口、战斗遭遇、检查点、支线空间和逐章增强的后室异变。

地图顺序：王后的命令 → 七人的庇护 → 不要开门 → 三次敲门 → 镜庭真名 → 玻璃棺。第五章真名及第六章唤醒白雪属于原创改编，通过归还真名、移除毒苹果残片完成解救。

## 等级成长

主线章节结束等级为10、20、30、40、50、60。每张必经地图首次完成主线任务时，按累计经验差额补足至该地图目标等级。支线和刷怪不是达到60级的必要条件；已经超过目标不降级。累计经验初稿：`total_xp(L)=100*(L-1)^2+50*(L-1)`，60级为351050经验。等级与保底奖励暂未接入游戏。

140是普通天赋上限，不代表主线发满140点。天赋点等级奖励需要另行制定。

## 地图与小地图

- 每张正式地图有独立ID、探索区域、出入口、传送点和任务节点。
- 局部小地图仅显示当前地图已探索区域，标记玩家、任务、敌人、NPC、宝箱和出口。
- M打开当前图；章节页展示本章8—9张地图连接；世界页展示六章进度。
- 目标在另一地图时，先指向对应出口；切图后再显示目标位置。
- 未解锁出口显示明确的任务或BOSS条件。

## 当前实现边界

`story_map.gd` 与 `minimap.gd` 目前是一张九剧情节点的压缩测试图，用于验证任务顺序、战斗门槛、小地图和存档。不是正式六章地图，也没有等级经验系统。九节点可达性检查不能作为51张地图的验收。
