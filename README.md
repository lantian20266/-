# 失序童话｜固定工程入口

更新日期：2026-10-27（北京时间）

本文件夹是后续制作的主工程。工程名暂为 FairyGreybox，游戏暂定名为《失序童话》。继续编辑这里的文件，避免另建一份造成版本混淆。

## 从这里开始

1. 阅读 `docs/项目设定.md`：了解已经确认的方向。
2. 阅读 `docs/开发状态.md`：区分设计、代码和已验证结果。
3. 阅读 `docs/下一步任务.md`：按顺序继续制作。
4. 阅读 `docs/六章地图与等级规划.md`：六章51图及1—60级目标；`data/campaign_maps.json` 保存相同规划数据。
5. 使用 Godot 4.7 打开 `project.godot`，按 F5 运行。

当前为0.3版白雪剧情试验地图。主场景已在Godot 4.7.2启动并通过50项地图流程检查；尚未完成人工通关、完整天赋功能与联机验收。

新内容见 `docs/剧情地图设计.md` 与 `docs/地图验证记录.md`。九个剧情地点通过线索和战斗串联，M展开全图，营地E保存进度。


## 当前控制

WASD 移动，鼠标瞄准，左键普攻，右键重击，空格闪避，Q 范围技能，E 调查/拾取/营地保存，M 展开全图，Tab 打开天赋球。天赋面板中可选择职业、两种起点之一和升华，拖动旋转、滚轮缩放。

存档使用 Godot 的用户数据目录 `user://build.cfg`，不是本工程目录。新版天赋图会重置旧版天赋分配，以免将旧节点错误对应到新节点。
